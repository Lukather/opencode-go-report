# OpenCode Go report

Analisi vivente dei modelli della sottoscrizione [OpenCode Go](https://opencode.ai/docs/go)
($10/mese): prezzi, allowance effettive (moltiplicatore), benchmark di terze parti,
finestre peak/off-peak DeepSeek e privacy per modello.

**Pagina pubblica:** https://lukather.github.io/opencode-go-report/

La tabella "Log dei cambiamenti" in fondo alla pagina viene aggiornata automaticamente
ogni giorno da un tracker che confronta la doc ufficiale con lo snapshot del giorno
precedente. Fonte primaria: solo `opencode.ai/docs/go`.

## Struttura

- `index.html` — il report (pagina pubblicata via GitHub Pages)
- Il sorgente completo (con sezioni private) vive fuori da questo repo
